# MCL Methodology Audit before Candidate Prioritization v2

## Цель аудита

Перед добавлением мутаций, экспрессии и copy number проверить, что MCL не смешивает разные типы доказательств и не превращает описательные эвристики в причинные выводы.

Главный исследовательский вопрос MCL:

> Какое вещество, через какую мишень, в каком опухолевом контексте и на каких клеточных моделях имеет смысл проверять в лаборатории?

Ответ должен быть воспроизводимым и разложенным по независимым осям доказательств.

---

## 1. Фармакологический фенотип PRISM

### Было

В Candidate Prioritization v1 модель считалась чувствительной, если входила в наиболее чувствительную четверть для конкретного вещества.

### Проблема

Относительный ранг существует даже для практически неактивного вещества. Поэтому верхняя четверть сама по себе не является доказательством биологически заметного эффекта.

### Решение

Для PRISM primary screen разделить два понятия:

1. **Абсолютная активность:** `LFC <= -1` — операционный MCL-порог выраженного depletion в single-dose primary screen. Этот порог не является универсальным законом фармакологии; он используется как консервативный навигационный критерий и имеет опубликованную калибровку на известных чувствительных контекстах.
2. **Относительная селективность:** положение модели относительно остальных моделей для того же вещества, например верхняя четверть чувствительности.

Высокий приоритет требует присутствия абсолютного эффекта; относительный ранг используется для выбора наиболее информативных моделей и оценки опухолевого обогащения.

PRISM primary screen: 2.5 µM, 5 суток, log-fold change относительно DMSO. Более отрицательное LFC означает более сильное depletion.

---

## 2. CRISPR: Gene Effect и Probability of Dependency

### Было

`Gene Effect <= -0.5` использовался как бинарный вызов зависимости.

### Проблема

DepMap рекомендует для бинарного деления dependent/non-dependent использовать `CRISPRGeneDependency.csv`, то есть Probability of Dependency. Gene Effect — непрерывная мера силы loss-of-function фенотипа.

### Решение

- **Бинарная зависимость:** `Probability of Dependency > 0.5`.
- **Сила фенотипа:** Chronos Gene Effect как непрерывное число.
- `Gene Effect <= -0.5` и `<= -1` можно показывать как описательные ориентиры depletion/strong depletion, но не использовать как замену официального probability call, если probability доступна.
- `Gene Effect = -1` — reference anchor common-essential-like effect, а не универсальный порог «сильной терапевтической мишени».

CRISPR knockout не эквивалентен фармакологическому ингибированию.

---

## 3. Согласованность фармакологии и CRISPR

### Корректная часть

Для ингибитора при PRISM LFC и Chronos Gene Effect ожидается положительная корреляция: более отрицательный Gene Effect и более отрицательный drug-response LFC должны двигаться в одном направлении.

### Ограничения

- корреляция не доказывает target engagement;
- полифармакология может давать чувствительность при отсутствии CRISPR-зависимости от одной аннотированной мишени;
- полный knockout может не соответствовать частичному, обратимому или аллостерическому ингибированию;
- пан-раковая корреляция может быть частично обусловлена lineage/context confounding;
- agonist/activator нельзя напрямую валидировать CRISPR loss-of-function тем же правилом.

### Решение

Согласованность остаётся отдельной осью механистической поддержки. Для v2 необходимо хранить raw pan-cancer concordance отдельно от контекстно-скорректированной оценки и не повышать агонисты/активаторы по loss-of-function правилу.

## 4. RNA expression

Источник DepMap `OmicsExpression...TPMLogp1`:

- значение = `log2(TPM + 1)`;
- 0 соответствует отсутствию детектируемой экспрессии в этой матрице.

### Решение

Не использовать один универсальный порог «высокой экспрессии» для всех генов.

Хранить:

- исходное `log2(TPM+1)`;
- `expression_detected`;
- относительный перцентиль экспрессии внутри опухолевого контекста при достаточном числе моделей (`n >= 5`).

Экспрессия поддерживает биологическую правдоподобность, но сама по себе не доказывает зависимость или лекарственную чувствительность.

---

## 5. Copy number

Источник `OmicsCNGeneWGS.csv` содержит **линейный относительный copy number**, а не абсолютное целочисленное число копий.

DepMap не рекомендует универсальные пороги amplification/deletion для этой relative-CN матрицы: интерпретация зависит от контекста и плоидности.

### Решение

MCL v2 хранит:

- исходное relative CN;
- перцентиль внутри опухолевого контекста при `n >= 5`.

MCL **не называет** высокий relative CN «амплификацией» и низкий relative CN «делецией» без отдельного валидированного источника/calling method.

## 6. Мутации DepMap 26Q1

DepMap 26Q1 обновил mutation pipeline. Финальный набор включает отфильтрованные/спасённые варианты и отдельные определения:

- `Hotspot`;
- `LikelyLoF`;
- protein/DNA change;
- allele fraction;
- VEP impact;
- дополнительные evidence flags.

### Критическая граница

`Hotspot == True` **не означает автоматически gain-of-function**.

`LikelyLoF == True` означает поддержку потери функции, но биологическая значимость зависит от роли гена, аллельности и контекста.

### Решение

Сначала мутации отображаются как самостоятельная молекулярная ось. Generic mutation presence не повышает автоматически финальный приоритет.

Для автоматического утверждения вида `BRAF V600E поддерживает ингибирование BRAF` нужен отдельный curated biomarker-rule layer с направлением эффекта и источником доказательств.

## 7. Положительные и отрицательные клеточные модели

### Положительная модель v2

Кандидат на положительную модель должен одновременно иметь:

1. выраженный фармакологический ответ (`PRISM LFC <= -1`);
2. высокую относительную чувствительность к тому же веществу;
3. Probability of Dependency для кодирующего гена мишени `> 0.5`, если этот показатель доступен;
4. релевантный опухолевый контекст.

Молекулярный контекст (мутация/expression/CN) показывается отдельно и усиливает интерпретируемость, но не заменяет эти критерии.

### Отрицательный контроль v2

Нужен измеренный, а не отсутствующий результат:

- Probability of Dependency доступна и `<= 0.5`;
- модель находится среди наименее чувствительных к веществу и не проходит абсолютный activity threshold;
- по возможности относится к тому же типу опухоли, чтобы уменьшить lineage confounding.

Отсутствующее CRISPR-измерение никогда не считается отсутствием зависимости.

---

## 8. Что пока нельзя включать в финальный вывод

До появления соответствующих слоёв нельзя утверждать:

- безопасность для нормальных тканей;
- наличие терапевтического окна;
- прямое связывание вещества с белком;
- конкретную изоформу/протеоформу мишени при gene-mapped аннотации;
- клиническую эффективность;
- пригодность дозы 2.5 µM для человека;
- причинность механизма только по PRISM + CRISPR.

---

## 9. Финальная архитектура доказательств v2

Для каждой гипотезы `compound × protein target × coding gene × cancer context` MCL должен хранить независимые оси:

1. абсолютный фармакологический эффект;
2. относительную селективность;
3. Probability of Dependency;
4. непрерывный Gene Effect;
5. фармакология ↔ CRISPR concordance;
6. mutation context;
7. RNA expression;
8. relative copy number;
9. опухолевую специфичность;
10. позднее — normal-tissue liability, human genetics, target engagement, ADMET.

Единого непрозрачного числового score не вводится.
