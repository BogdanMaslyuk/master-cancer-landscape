# MCL: обогащение структур известных соединений v1

## Почему появился этот слой

PRISM Repurposing Public 24Q2 содержит фармакологические профили и аннотации соединений, однако конкретный загруженный файл метаданных не обязан содержать SMILES. Нормализатор MCL сохраняет `canonical_smiles`, только если поле структуры присутствует в исходных метаданных. Поэтому наличие столбца в `compound_catalog.parquet` не означает фактическое наличие структур.

Для расчёта Morgan/Tanimoto собственных молекул нельзя подменять отсутствующие структуры предположениями. Поэтому структуры известных соединений обогащаются отдельным, трассируемым слоем.

## Универсум

Обогащаются не все 6789 PRISM-профилей автоматически, а известные соединения, которые связаны с генами-мишенями, имеющими хотя бы одну гипотезу Candidate v2 со статусом `priority_for_in_vitro`.

Это соответствует текущей задаче: сначала биологический фильтр MCL, затем химическое сравнение.

## Источники и приоритет разрешения

Для каждого соединения:

1. Если структура уже есть в нормализованном MCL-каталоге — используется она.
2. Если структуры нет, выполняется запрос PubChem PUG REST.
3. Порядок идентификаторов:
   - явный PubChem CID;
   - `preferred_name`;
   - ChEMBL ID как PubChem synonym/name;
   - Broad ID как PubChem synonym/name.
4. Результат принимается автоматически только если один запрос разрешается ровно в один уникальный PubChem CID.
5. Неоднозначные результаты не выбираются автоматически и попадают в QC.

## Почему исходный каталог не перезаписывается

`compound_catalog.parquet` остаётся отражением нормализованного исходного фармакологического слоя. Внешнее обогащение хранится отдельно:

- `data/runtime/pharmacology/compound_structure_registry.parquet`
- `data/runtime/pharmacology/compound_structure_registry.tsv`
- `data/runtime/pharmacology/compound_structure_registry_manifest.json`
- `outputs/qc/compound_structure_registry_qc.tsv`

Перед Tanimoto строится временный объединённый каталог:

- `data/runtime/pharmacology/compound_catalog_structures_enriched.parquet`

Так сохраняется происхождение данных и можно отличить структуру из исходного PRISM/Broad-файла от структуры, разрешённой через PubChem.

## Научное ограничение

Успешное разрешение структуры через PubChem подтверждает химическую идентичность, необходимую для 2D-сравнения, но не подтверждает целевой белок, тип фармакологического действия, аффинность, селективность или клеточный механизм. Эти утверждения по-прежнему берутся только из соответствующих доказательных слоёв MCL.

## Запуск

Обычный запуск:

```powershell
.\scripts\build-own-compound-similarity.ps1
```

Он последовательно:

1. строит/обновляет реестр структур известных соединений;
2. накладывает этот реестр на фармакологический каталог без изменения исходника;
3. рассчитывает Morgan radius 2 / 2048 bits и Tanimoto для 20 собственных соединений.

Повторно запросить PubChem даже для уже разрешённых соединений:

```powershell
.\scripts\build-own-compound-similarity.ps1 -ForceStructureRefresh
```

Обычный повторный запуск использует локальный реестр для уже успешно разрешённых структур и не должен заново запрашивать их у PubChem.
