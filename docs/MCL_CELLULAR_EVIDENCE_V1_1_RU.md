# MCL Cellular Evidence Layer v1.1

## Зачем понадобилось v1.1

В первой реализации Cellular Evidence Layer Target Ligand Space и PRISM связывались только по точному стандартизированному InChIKey из `data/runtime/pharmacology/compounds.parquet`.

На локальном запуске было получено:

`No exact standardized structures overlap between Target Ligand Space and PRISM compounds.`

Это не означает, что в PRISM отсутствуют вещества, присутствующие в ChEMBL/BindingDB. Причина в том, что нормализованный PRISM 24Q2 у MCL может не содержать SMILES для профилей, даже когда известны название вещества и/или Broad ID. В таком случае точное структурное сопоставление невозможно до восстановления химической идентичности профиля.

## Что делает v1.1

Перед построением клеточного слоя создаётся отдельный реестр:

`data/runtime/pharmacology/prism_structure_registry.parquet`

Структуры PRISM разрешаются в следующем порядке:

1. структура уже присутствует в нормализованном источнике PRISM;
2. структура уже была разрешена в существующем MCL `compound_structure_registry.parquet`;
3. выполняется консервативный запрос PubChem PUG REST по PubChem CID, названию вещества, ChEMBL ID или Broad ID, если такие поля доступны.

После получения структуры она повторно стандартизируется одинаковым способом:

`RDKit Cleanup -> FragmentParent -> canonical isomeric SMILES -> InChIKey`

Только после этого Target Ligand Space и PRISM связываются по точному совпадению стандартизированного parent InChIKey.

## Кэш и возобновление

Реестр является кэшем. Повторный запуск не должен заново запрашивать уже обработанные соединения. Во время большого первого запуска создаются контрольные сохранения, поэтому процесс можно продолжить после прерывания.

Ключи запуска:

- обычный запуск: использовать кэш;
- `-RetryUnresolvedPrismStructures`: повторно попробовать только ранее неразрешённые профили;
- `-ForcePrismStructureRefresh`: пересобрать весь реестр заново.

## Научное ограничение

PubChem здесь используется только как источник химической идентичности. Разрешение PRISM-профиля через PubChem не доказывает его мишень и не доказывает, что клеточный эффект обусловлен механизмом, указанным для похожего или идентичного лиганда.

Причинная интерпретация по-прежнему требует совокупности независимых слоёв:

- прямое измерение белок–лиганд (Ki/Kd/IC50);
- клеточный фенотип PRISM;
- CRISPR-зависимость DepMap;
- согласованный опухолевый контекст;
- по возможности target-engagement и независимая экспериментальная валидация.
