# MCL — интерпретация CRISPR-зависимостей отдельной клеточной модели

## Что ранжируется

Для каждой модели MCL использует значения **DepMap Chronos Gene Effect** для всех генов, доступных в `CRISPRGeneEffect.csv` выбранного релиза.

Гены сортируются по Gene Effect по возрастанию:

- более отрицательное значение — более сильное ухудшение роста/жизнеспособности после CRISPR-нокаута;
- значение около 0 — выраженной зависимости не показано;
- MCL использует `Gene Effect <= -0.5` как рабочий порог для навигационной классификации сильной зависимости.

Этот порог не является клиническим порогом и не означает, что белок автоматически является лекарственной мишенью.

## Ранг внутри модели

`rank = 1` получает ген с наиболее отрицательным Gene Effect в выбранной модели.

`rank_percentile` показывает, насколько высоко ген находится среди всех измеренных генов этой модели. Это внутримодельная характеристика и не заменяет сравнение с другими моделями.

## Классификация распространённости зависимости

Классы ниже являются **эвристической навигационной классификацией MCL**, построенной по частоте `Gene Effect <= -0.5` среди проиндексированных опухолевых моделей DepMap.

### Широкая базовая зависимость

Сильная зависимость присутствует минимум у 80% проиндексированных опухолевых моделей.

Важно: это не доказывает, что ген одинаково необходим всем нормальным клеткам организма.

### Широкая опухолевая зависимость

Сильная зависимость присутствует минимум у 40%, но менее чем у 80% моделей.

### Обогащена в этом типе опухоли

Используется, если:

- для данного типа опухоли доступно не менее 5 моделей;
- минимум 50% моделей этого типа имеют `Gene Effect <= -0.5`;
- доля зависимых моделей в данном типе опухоли как минимум на 20 процентных пунктов выше общей доли по DepMap;
- общая доля сильной зависимости ниже 40%.

### Особенно выражена в этой модели

Используется для редкой сильной зависимости, если одновременно:

- общая доля моделей с `Gene Effect <= -0.5` не превышает 10%;
- Gene Effect выбранной модели <= -0.8;
- Gene Effect выбранной модели как минимум на 0.5 ниже общей медианы этого гена по DepMap.

### Селективная зависимость

Сильная зависимость (`Gene Effect <= -0.5`), которая не соответствует критериям более широких категорий выше.

### Слабая / невыраженная

Gene Effect выше -0.5.

## Функциональные кластеры

Функциональный кластер не выводится из названия гена. MCL использует существующий индекс `gene_explorer/gene_catalog.parquet` и таксономию `config/mcl_functional_domains.yaml`, построенные поверх формальных аннотаций проекта.

Один ген может относиться к нескольким функциональным доменам и поддоменам.

## Что нельзя заключать из этой страницы

1. Сильная CRISPR-зависимость не доказывает лекарственную ингибируемость белка.
2. Широкая зависимость среди опухолевых линий не равна токсичности для нормальных тканей.
3. Уникальная зависимость одной линии может отражать редкий генетический фон или технический эффект и требует воспроизводимости.
4. Для терапевтической гипотезы дополнительно нужны генетический контекст, экспрессия, копийность, данные других моделей, пациентские данные, лекарственная доступность и экспериментальная валидация.
