# MCL Laboratory Panel v1.1 / Mechanism Context v1

## Зачем нужен этот слой

Candidate v2 отвечает на вопрос, какие сочетания «вещество × мишень × опухолевый контекст» имеют вычислительную поддержку. Laboratory Panel отвечает на другой вопрос: какие из этих гипотез можно проверить на культурах, физически доступных на кафедре.

Mechanism Context v1 добавляет третий вопрос: можно ли собрать из доступных культур биологически интерпретируемую контрастную панель, а не просто проверить снижение жизнеспособности одной линии.

Лабораторная доступность не увеличивает доказательность механизма и не является клиническим приоритетом.

## Идентичность линий

Автоматическое сопоставление с DepMap использует только точные нормализованные имена/синонимы. Если одному имени соответствуют несколько ModelID, MCL не выбирает один из них автоматически.

Кураторские решения хранятся отдельно в `config/laboratory_identity_overrides.tsv`.

На этапе v1.1:

- A549 принудительно сопоставляется с `ACH-000681` как стандартной A549. `ACH-003012` рассматривается как отдельная производная A549CRAFKD.
- PC3 принудительно сопоставляется с `ACH-000090` как стандартной линией рака предстательной железы. `ACH-002184` — отдельная модель PC3JPC3_LUNG.
- U251 не разрешается автоматически. `ACH-000232` хранится как предпочтительный кандидат U251MG, но `ACH-001172` (U251MGDM) является отдельной дрейфовавшей производной. До подтверждения происхождения кафедральной культуры U251 исключена из автоматического лабораторного triage.

`preferred_only` никогда не превращается в фактическое сопоставление и не участвует в расчётах как ModelID.

## BJ5ta

BJ5ta — единственный доступный человеческий неопухолевый контроль кафедры.

Она используется как общий экспериментальный контроль цитотоксичности/селективности, но:

- это hTERT-иммортализованные фибробласты;
- это не первичная нормальная ткань;
- это не органоспецифический контроль для молочной железы, простаты, мозга и т. д.;
- отсутствие DepMap/PRISM-профиля не мешает использовать BJ5ta экспериментально;
- сравнение опухолевой линии с BJ5ta не следует называть доказанным терапевтическим окном.

## Первая панель: PIK3CA / рак молочной железы

Фокусные культуры:

- MCF7;
- T47D;
- MDA-MB-231;
- BT-474;
- SK-BR-3;
- BT-549;
- BJ5ta.

Вещества первой версии:

- taselisib;
- CH5132799.

Основная мишень: `PIK3CA`.

Дополнительный контекст: `PIK3CA`, `PTEN`, `KRAS`.

Текущие Candidate v2 данные уже выделили MCF7/T47D как положительные модели и MDA-MB-231 как отрицательный опухолевый контроль для этих PIK3CA-гипотез. Остальные доступные линии добавляются в механистическую панель как дополнительные модели, но их роль определяется только наличием фактических PRISM/CRISPR данных.

Hotspot/LikelyLoF-флаги показываются описательно. MCL v1 не предполагает автоматически, что любой PIK3CA hotspot означает чувствительность или что любой KRAS/PTEN-контекст означает резистентность.

## Вторая панель: MDM2 / TP53

Фокусные культуры:

- 22Rv1;
- LNCaP;
- HCT116;
- U2-OS;
- U87;
- BJ5ta.

Вещества первой версии:

- idasanutlin;
- CGM097;
- AMG-232;
- SAR405838;
- RG7112.

Основная мишень: `MDM2`.

Ключевой контекст: `TP53` и `MDM2`.

Правила интерпретации TP53:

1. `TP53 LikelyLoF` — механистическое предостережение для гипотезы ингибирования MDM2.
2. `TP53 hotspot` — повод разобрать конкретный вариант; hotspot не равен автоматически потере функции.
3. Отсутствие LikelyLoF/hotspot-флага не означает автоматически `TP53 wild-type` и не доказывает сохранную функцию p53.
4. Окончательная валидация механизма требует функционального readout p53/MDM2, а не одной аннотации мутации.

## Научное ограничение

Mechanism Context v1 — слой планирования следующего эксперимента. Он не доказывает:

- прямое связывание вещества с белком;
- target engagement;
- причинность найденного биомаркера;
- безопасность для нормальных тканей;
- эффективность in vivo;
- клиническую перспективность.

В MCL по-прежнему не используется единый искусственный числовой score для объединения этих разных типов доказательств.
