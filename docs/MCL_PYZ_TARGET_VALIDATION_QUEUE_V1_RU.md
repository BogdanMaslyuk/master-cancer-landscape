# MCL PYZ Target Validation Queue v1

## Зачем нужен этот слой

После `PYZ Target Evidence Matrix v1` из 845 пар `PYZ × мишень` осталось 10 исследовательских пар с Tanimoto >= 0,35. Это не подтвержденные мишени PYZ. Задача текущего слоя — превратить короткий список в воспроизводимую очередь ортогональной проверки без искусственного суммарного балла.

## Основной принцип

Низкое 2D-сходство 0,35–0,50 дает только исследовательскую гипотезу. Активность известного лиганда не переносится количественно на PYZ. Поэтому следующая ступень — независимый structure-based метод, а затем прямой биохимический/биофизический эксперимент.

Очередь строится по прозрачным правилам:

1. **Фаза 1 — ортогональная проверка.** Пара уже прошла Tanimoto >= 0,35, а ближайший непосредственно измеренный лиганд имеет Ki/Kd/IC50 <= 1 мкМ.
2. **Фаза 2 — представитель повторяющегося химического предположения.** Если несколько PYZ имеют один и тот же ближайший известный лиганд, первым идет PYZ с максимальным Tanimoto. Это уменьшает дублирование.
3. **Фаза 2 — вторичная проверка.** Уникальные пары с заметным сходством, но более слабым известным лигандом.
4. **Фаза 3 — расширение внутри химического семейства.** Остальные PYZ, у которых тот же ближайший лиганд, проверяются только после сигнала у представителя.

## Структурная проверка

Для каждой мишени очереди заранее задан inhibitor-bound PDB-контекст. Перед docking PYZ обязателен redocking сокристаллизованного лиганда. Если redocking не воспроизводит исходный карман/позу на приемлемом уровне, этот рецептор нельзя использовать как основание для интерпретации docking PYZ.

### CDK4

- `7SJ3` — активный CDK4-cyclin D3 с abemaciclib; основной рецептор.
- `9CSK` — CDK4-cyclin D1 с atirmociclib; независимый второй рецептор для проверки зависимости результата от конформации.

Использование двух структур — не «усиление доказательств» само по себе. Оно лишь снижает риск сделать вывод из одной случайной конформации белка.

### BCL2L1 / BCL-xL

- `2YXJ` — человеческий BCL-xL в комплексе с ABT-737; основной inhibitor-bound контроль BH3-кармана.

## Как интерпретировать docking

Docking не является доказательством:

- связывания PYZ с мишенью;
- Ki/Kd/IC50;
- селективности;
- target engagement в клетке;
- противоопухолевой активности;
- причинности клеточного эффекта.

Он используется только как независимый способ решить, какие пары заслуживают прямого эксперимента.

## Следующие прямые эксперименты

### CDK4

После согласованного результата structure-based проверки: прямой kinase assay CDK4/cyclin-D и независимый binding/target-engagement метод. Фенотип на опухолевых клетках оценивается отдельно.

### BCL2L1

После согласованного результата structure-based проверки: прямой BCL-xL binding либо BH3-peptide displacement assay. Клеточный апоптоз — отдельный слой доказательств и не заменяет прямое связывание.

До прямого измерения PYZ-target interaction все пары сохраняют статус `direct_pyz_target_evidence = absent_not_measured`. Очередь определяет порядок проверки, а не вероятность того, что мишень действительно является мишенью PYZ.
