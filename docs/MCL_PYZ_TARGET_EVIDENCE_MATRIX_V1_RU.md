# MCL PYZ Target Evidence Matrix v1

## Зачем нужен этот слой

После Target Ligand Space и Cellular Evidence Layer у MCL появились несколько независимых типов доказательств:

1. 2D-структурное сходство PYZ с экспериментальными лигандами 13 приоритетных мишеней;
2. прямые экспериментальные Ki, Kd и IC50 для известных лигандов;
3. клеточная активность части этих лигандов в PRISM;
4. CRISPR-зависимость тех же клеточных моделей по DepMap;
5. контекст приоритетных опухолей Candidate v2;
6. отдельный preclinical-контекст PCDB для известных соединений вокруг мишени;
7. строгий набор противоопухолевых эталонов уровней A/B.

Эти данные нельзя смешивать в один непрозрачный балл. Matrix v1 хранит их рядом, чтобы исследователь видел, **какой именно тип данных поддерживает гипотезу и где заканчивается доказательство**.

## Главная единица анализа

Одна строка матрицы = одна пара:

`PYZ-XXX × target_gene`

При 65 PYZ и 13 приоритетных мишенях ожидается 845 строк.

## Самое важное правило интерпретации

Клеточные и CRISPR-данные относятся к **известному экспериментальному лиганду**, а не к PYZ.

Даже если известный лиганд имеет сильное согласование PRISM + CRISPR, это не позволяет переносить его механизм на PYZ, если PYZ структурно на него не похожа.

Поэтому Matrix v1 разделяет:

- качество данных известного лиганда;
- структурную переносимость этих данных на PYZ.

## Классы структурной переносимости

Используется Morgan fingerprint radius 2, 2048 bits и Tanimoto — те же настройки, что в Target Ligand Space.

| Tanimoto | Класс | Интерпретация |
|---|---|---|
| ≥ 0,70 | `high_structural_transferability` | Высокое 2D-сходство. Всё равно только проверяемая гипотеза, не доказательство одинаковой мишени. |
| 0,50–0,70 | `moderate_structural_transferability` | Умеренное сходство. Разумно переходить к направленной проверке мишени. |
| 0,35–0,50 | `exploratory_low_structural_similarity` | Низкое, но заметное сходство. Только исследовательская гипотеза. |
| < 0,35 | `mechanism_not_transferable_by_2d_similarity` | Механизм известного лиганда нельзя переносить на PYZ по 2D-структуре. |

Порог 0,35 используется только как навигационный порог для исследовательского shortlist. Он не является валидированным порогом общего механизма действия.

## Что содержит матрица

### 1. Target Ligand Space

Для каждой `PYZ × мишень` сохраняются:

- число экспериментальных лигандов, с которыми проведено сравнение;
- лучший Tanimoto;
- лучший известный лиганд;
- число соседей с Tanimoto ≥0,35 / ≥0,50 / ≥0,70;
- минимальное опубликованное Ki/Kd/IC50 ближайшего лиганда и тип endpoint.

Ki, Kd и IC50 не считаются взаимозаменяемыми. Минимальное числовое значение используется только для навигации и всегда хранится вместе с типом endpoint.

### 2. Сильные прямые лиганды среди top-20 структурных соседей

Дополнительно сохраняется лучший по Tanimoto сосед среди top-20, у которого опубликовано значение:

- ≤100 нМ;
- ≤1000 нМ.

Это не означает, что один endpoint лучше другого и не является рейтингом potency между Ki/Kd/IC50.

### 3. Cellular Evidence для того же самого лучшего структурного соседа

Отдельно проверяется, представлен ли **именно лучший структурный лиганд** в Cellular Evidence Layer.

Если да, сохраняются:

- cellular evidence label;
- число PRISM-моделей;
- число чувствительных моделей;
- число моделей с одновременной PRISM-чувствительностью и CRISPR-зависимостью;
- корреляция профилей;
- разница ответа dependent vs other.

Это принципиально важнее, чем просто наличие какого-либо другого клеточно изученного лиганда той же мишени.

### 4. Лучший клеточно охарактеризованный сосед среди сохранённых top-20

Cellular Evidence Layer может найти сильный по биологии известный лиганд, который структурно гораздо дальше от PYZ, чем основной химический сосед.

Поэтому Matrix v1 хранит его отдельно:

- `best_cellular_ligand_id`;
- `best_cellular_tanimoto`;
- cellular evidence label;
- число PRISM-sensitive моделей;
- число joint PRISM + CRISPR моделей.

Если `best_cellular_tanimoto < 0,35`, автоматически добавляется предупреждение, что механизм этого известного лиганда нельзя переносить на PYZ.

### 5. Strict Oncology Reference

Если слой уже построен, матрица добавляет лучший A/B противоопухолевый маломолекулярный эталон по той же мишени и его Tanimoto.

Это отдельная проверка: похожа ли PYZ не просто на экспериментальный лиганд, а на более строго отобранное онкологическое соединение.

### 6. Candidate v2

Для каждой мишени добавляется:

- число `priority_for_in_vitro` гипотез;
- число приоритетных опухолевых контекстов;
- идентификаторы и названия этих опухолей.

Это контекст мишени, а не доказательство действия PYZ.

### 7. PCDB

Если preclinical layer доступен, добавляется только **target-level контекст**:

- сколько известных target-linked compounds имеют записи PCDB;
- сколько имеют oncology-like контекст;
- сколько имеют exact priority-cancer контекст.

PCDB не содержит доказательства эффективности PYZ, не доказывает target engagement и не подтверждает, что наблюдавшийся in-vivo эффект известного вещества опосредован именно рассматриваемой мишенью.

## Почему нет итогового балла 0–100

Один числовой score здесь создавал бы ложную точность и смешивал принципиально разные сущности:

- химическое сходство;
- прямую фармакологию;
- клеточную активность;
- CRISPR-зависимость;
- опухолевый контекст;
- in-vivo контекст.

Matrix v1 сознательно оставляет оси раздельными.

## Shortlist

`pyz_target_validation_shortlist.tsv` содержит только пары с:

`best Tanimoto >= 0.35`

Это **не список доказанных мишеней PYZ**.

Это список пар, для которых 2D-химия хотя бы достигает заранее определённого исследовательского порога и поэтому оправдана следующая стадия проверки.

## Что разрешено делать с shortlist

Для пар ≥0,35 разумно:

1. проверить мишень независимым ligand-based методом;
2. оценить доступность пригодной экспериментальной структуры белка;
3. выполнить docking как инструмент приоритизации;
4. проверить устойчивость результата на разных структурах/состояниях белка;
5. при сохранении гипотезы перейти к прямому biochemical/biophysical assay;
6. затем проверять фенотип на релевантных положительных и отрицательных клеточных моделях.

## Что запрещено утверждать

На основании Matrix v1 нельзя писать:

- «PYZ связывает мишень X»;
- «PYZ ингибирует X»;
- «PYZ имеет тот же механизм, что известный лиганд»;
- «сильная PRISM + CRISPR поддержка известного лиганда подтверждает действие PYZ»;
- «низкое Tanimoto исключает активность PYZ против мишени».

Корректная формулировка:

> «Для пары PYZ × мишень обнаружен структурный сосед среди экспериментально исследованных лигандов. Степень 2D-сходства и независимые данные по известному лиганду используются для приоритизации последующей проверки, но не доказывают прямое взаимодействие PYZ с мишенью.»
