## 3. Выявленный недостаток программы аудита (исправлен в PR №12)

`AnnotatedGeneExplorerStore.materialize_indexes()` устраняет дубли по полному ключу:
`gene_symbol, annotation_type, annotation_id, source, source_id`.

Первый AC-02 ошибочно использовал более короткий ключ `gene_symbol, annotation_type, annotation_id`. Две разные экспериментальные/справочные ссылки могут поддерживать одну классификацию гена; их **нельзя автоматически объединять как дубликаты научных фактов**.

Исправление в коде:
- `coarse_annotation_repeats` остаётся информативной статистикой.
- `duplicate_keys` теперь измеряет **точные** повторы с учётом `source` и `source_id`.
- Если эти столбцы отсутствуют, требуется отдельная проверка происхождения, а не фиктивное утверждение о точных дублях.
- Чётко разделены `sidecar_present`, `sidecar_missing` и `sidecars_unchanged`; отсутствующий JSON не называется изменённым.

**Важно:** фактическое количество точных дубликатов ещё не известно: для него требуется повторный запуск исправленного аудитора на локальной Parquet-таблице. Отчёт от 21:36 содержит только результат прежней логики.
