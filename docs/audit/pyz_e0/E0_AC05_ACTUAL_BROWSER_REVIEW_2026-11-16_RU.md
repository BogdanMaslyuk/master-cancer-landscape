## Единственный открытый технический вопрос

На `/pyz` в первом тесте при 1440 px записан **отсутствующий ресурс с HTTP 404**, но в архиве нет URL этого ресурса. Сам документ вернул HTTP 200. Текущий анализатор ошибочно назвал это `JS_OR_HTTP_5XX_ERRORS` — из текста консоли не следует ни ошибка выполнения JavaScript, ни HTTP 5xx.

Поэтому **не объявлять неисправность API, JS или сайта доказанной**. Повторить короткую ресурсную диагностику с адресом и кодом ответа; если отсутствует только favicon/необязательная иконка — устранить отдельно, если критический скрипт/стиль — исправить до приёмки.

В этом PR улучшен анализатор: HTTP 4xx ресурсов сохраняются отдельно, с относительным URL, HTTP-статусом и типом ресурса; JS и HTTP 5xx остаются отдельными сигналами. Результат `HTTP_4XX_RESOURCE_WARNING` не трактуется как доказательство ошибки JavaScript.
