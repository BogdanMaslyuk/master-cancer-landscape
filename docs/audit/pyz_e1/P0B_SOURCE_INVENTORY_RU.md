# MCL / PYZ — Э1-P0-B. Инвентаризация источников известных лигандов

**Статус:** подготовка научной сверки. Не является утверждением assays. Э0 ещё формально не принят, Э1-P0-A — отдельный черновой PR №6.

## Научная задача

Проверить происхождение экспериментальных чисел для известных структурных аналогов PYZ-035/CDK4 и PYZ-055/BCL2L1.

1. Из текущей таблицы Target Ligand Space similarity top hits выбрать до пяти первых структурных соседей для каждой пары.
2. Сопоставить ligand_id с ligand_catalog только по точной паре target_gene + ligand_id.
3. Обязательно подтвердить идентичность InChIKey top-hit и каталога. При расхождении или неоднозначности связь запрещена.
4. Соединить каталог с ligand_measurements по target_gene + inchikey; сохранить отдельно каждую строку Ki/Kd/IC50, знак равенства/границы, идентификаторы источника/опыта/публикации.
5. Инвентаризировать доступные локальные файлы BindingDB Articles, Assays, rsid_eaids и существующие P0.3.6 отчёты.
6. Не интерпретировать результаты известных лигандов как измерения PYZ. Наличие assay_id в ChEMBL не означает ручную научную верификацию.

## Важное ограничение BindingDB

В v1 REST сохранён MonomerID без однозначного Reactant_set_id. Нельзя присоединять эти записи к P0.3.6 Assays по одному названию, DOI, сходству структуры или IC50. Допустим лишь подтверждённый путь через исходный Reactant_set_id и таблицу rsid_eaids с проверкой методов и публикаций.

## Файлы

- scripts/audit_pyz_e1_p0b_sources.py: read-only аудит.
- tests/test_pyz_e1_p0b_sources.py: синтетические проверки корректности связей.
- inventory_report.json: отчёт по статусам и источникам.
- neighbors_audit.tsv: отдельная строка на структурный аналог и причины незакрытых связей.
- measurement_source_candidates.tsv: фактические строки измерений известных лигандов с assay/document ID при наличии.
- local_source_inventory.tsv: обнаруженные исходные архивы и промежуточные отчёты P0.3.6.

## Запуск

Использовать отдельную рабочую копию ветки feature/pyz-e1-p0b-source-inventory от b6ba9ff.

Передать скрипту science-root = MCL_Project/repositories/mcl-pyz-v2-review, ligand-root = MCL_Project/repositories/mcl-tls-v2, scan-root = mcl-tls-v2 и MCL_Project/documents/MCL, out-dir = новый каталог внутри MCL_Project/reports.

Скрипт не запускает сервер, не перезаписывает документы, Parquet или исходные научные данные. Отчёт нельзя записывать внутрь исходных worktree. Подробная команда передаётся в чате.

## Интерпретация

EXACT_STRUCTURE_MATCH_PENDING_SOURCE_REVIEW: точный локальный структурный переход, НЕ подтверждение первичного assay.

SOURCE_ASSAY_ID_UNREVIEWED: ChEMBL содержит идентификатор записи assay, но её методика/публикация ещё не одобрена.

ASSAY_ID_MISSING: первичный идентификатор отсутствует, не восстанавливать догадкой.

NO_PRIMARY_ASSAYS_APPROVED: неизменный итог инвентаризации.

Для следующего этапа — использовать уже реализованные scripts/link_bindingdb_assays_p036.py и scripts/triage_bindingdb_assays_p036.py в TLS v2 для официальных исходных архивов, если полный комплект и связь по Reactant_set_id действительно доступны. Все присвоения статусов требуют проверки первичных методик.
