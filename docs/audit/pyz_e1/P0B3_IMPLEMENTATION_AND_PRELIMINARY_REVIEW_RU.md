# Э1-P0-B3 — Реализация и предварительные научные выводы

## Что реализовано

- `scripts/audit_pyz_e1_p0b3_evidence.py`: чтение отчёта Э1-P0-B2 из ZIP, сверка структуры и источников, реестр, список пяти публикаций, индивидуальные контрольные листы, JSON-отчёт.
- `scripts/run_pyz_e1_p0b3_evidence.ps1`: безопасный запуск из `MCL_Project`, автоматический поиск готового ZIP Э1-P0-B2, проверка неизменности входного SHA-256, новый результат в `reports`.
- `tests/test_pyz_e1_p0b3_evidence.py`: синтетические проверки сохранности источника, неприсвоения PYZ чужих измерений, целостности связей, проверки хэшей и невозможности автоматической научной приёмки.

## Запуск из проекта

Обновить отдельное рабочее дерево ветки Э1-P0-B3, запустить `powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$Review\scripts\run_pyz_e1_p0b3_evidence.ps1" -Root "$env:USERPROFILE\MCL_Project"`. Это создаст `reports/MCL_E1_P0B3_RESULT_*.zip` **без повторного скачивания полной BindingDB**.

## Предварительные факты по приоритетным публикациям

**CDK4:** 2015 работа Jorda и соавторов (PMID 25835357) исследует арил-азопиразольные ингибиторы CDK, сообщает о различающихся профилях избирательности и клеточных эффектах нескольких соединений. Значение IC50 420 нМ в локальной BindingDB относится к известному лиганду `TLS-E9F4B0F8F341CA`, а не к PYZ-035. Проверка оригинальной структуры и конкретного ферментного анализа остаётся открытой.

**BCL2L1:** статья Stornaiuolo и соавторов (PMID 25668341) посвящена прямым активаторам **BAX**, поэтому Ki известного структурного аналога в отношении BCL-xL не равно доказательству селективного функционального ингибирования BCL-xL или активации BAX нашей PYZ-055. BindingDB содержит информацию о вытеснении FITC-BIM из рекомбинантного BCL-xL методом флуоресцентной поляризации; необходимо подтвердить соответствие *конкретной строки* первичной методике.

**AAP1742:** BindingDB содержит IC50 CDK4 454 нМ и 450 нМ для MonomerID 123786. Это **две строки**, а не доказанные независимые эксперименты. Изменяется комплекс и описание метода; требуется сверка исходных работ 2014/2015 годов и эксперимента на уровне идентификаторов.

## Чёткая граница

Автоматическая трассировка источника **не равна научной верификации**. До ручной проверки всех необходимых первичных параметров статус каждой строки — `NO_PRIMARY_ASSAYS_APPROVED`. Измерения известных лигандов никогда не записываются как измерения PYZ, а ADMET-модуль остаётся отдельным проектом для будущей интеграции.
