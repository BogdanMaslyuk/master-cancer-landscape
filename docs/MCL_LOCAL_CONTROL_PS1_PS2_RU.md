# MCL PYZ 2.0 — быстрое управление PS1 и PS2

Двойной щелчок по файлу `MCL_CONTROL.cmd` из корня репозитория открывает меню. Оно запускает два отдельных окна PowerShell:

- **PS1** — FastAPI с научными данными текущей копии MCL, порт `8100`.
- **PS2** — Next.js, порт `3100`; интерфейс использует API `http://127.0.0.1:8100`.

| Клавиша | Действие |
| --- | --- |
| 1 | Запустить PS1 и PS2 |
| 2 | Перезапустить оба |
| 3 | Перезапустить только PS1 |
| 4 | Перезапустить только PS2 |
| 5 | Проверить состояние |
| 6 | Открыть карточку PYZ-035 |
| 7 | Остановить оба |
| 0 | Закрыть меню, **не останавливая** серверы |

## Первый запуск

Один раз закройте прежние **вручную** запущенные окна PS1 и PS2 при помощи `Ctrl+C`. Дальше запускайте обе службы через `MCL_CONTROL.cmd` и управляйте ими из меню.

Пульт **никогда не завершает чужие процессы**, даже когда они занимают порты 8100/3100. Менеджер хранит PID и время создания своих окон в `.mcl-dev/*.json` и проверяет их перед остановкой. Он закрывает только подтверждённую группу процессов своего окна (PowerShell и его дочерние процессы). Данные проекта не удаляются.

## Команды без меню

Из любого PowerShell:

```powershell
$Review = "$env:USERPROFILE\Desktop\mcl-pyz-v2-review"
& "$Review\scripts\dev-control.ps1" start all
& "$Review\scripts\dev-control.ps1" restart all
& "$Review\scripts\dev-control.ps1" restart api
& "$Review\scripts\dev-control.ps1" restart web
& "$Review\scripts\dev-control.ps1" status
& "$Review\scripts\dev-control.ps1" stop all
```

Если PS1 или PS2 завершился с ошибкой, его окно останется открытым для чтения сообщения. Выберите в меню `5` (состояние), затем `3` или `4` для перезапуска.

Изменения кода API автоматически перезагружаются через `uvicorn --reload`, а изменения интерфейса — через режим разработки Next.js. После замены файлов `parquet`/`tsv` используйте пункт **3**, поскольку научные таблицы могут находиться в памяти API.

PS1 ищет Python в `.venv` новой копии, а при его отсутствии — в соседних `master-cancer-landscape` и `mcl-vnext-review`. Исполняемый код API берётся **из новой копии**, благодаря `PYTHONPATH` и `--app-dir`. При отсутствии `node_modules` PS2 автоматически выполняет `npm ci` только в новой папке.

Ни одна команда не скачивает научные данные, не пересчитывает ADMET/CRISPR/BindingDB, не меняет ветки Git и не касается старого сайта на портах 8000/3000.

## Если сайт отвечает ошибкой отсутствующего Gene Explorer

Пульт управляет процессами, а не содержимым научных индексов. Проверьте, что каталог `data/runtime/explorer` вместе с `model_layers` уже перенесён в `mcl-pyz-v2-review`. Отсутствующие индексы нельзя исправить перезапуском.

## Принцип безопасности

- В отдельном рабочем дереве `mcl-pyz-v2-review` состояние менеджера локальное и игнорируется Git.
- Если порт занят незарегистрированным процессом, новый экземпляр не запускается и чужой процесс не завершается.
- Существующие исследовательские данные и `review/vnext` не изменяются.
