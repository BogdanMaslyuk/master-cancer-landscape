# MCL Scientific Core v2.1 — реализация первого рабочего этапа P0/P1

**Статус:** первый программный маршрут для собственных клеточных измерений реализован в тестовой ветке. ТЗ v2.1 в целом НЕ выполнено: P2–P4 требуют дальнейшей разработки и независимых лабораторных данных.

## Реализованные возможности

1. Отдельные клеточные записи HEK293, HEK293T, HEK293FT, MRC-5 и BJ5ta. Последняя и две HEK-производные только зарегистрированы; MRC-5 — планируемая модель без подтверждённого наличия. Ни одна запись не отмечена готовой к опыту.
2. Просмотр полного каталога PYZ-001–065. Физическая партия, химическая идентичность, чистота и доступность отдельно не подтверждены.
3. Создание проекта эксперимента с точным вариантом культуры, набором веществ, протоколом и длительностью.
4. Импорт данных 96-луночного планшета из UTF-8 CSV, включая исходные байты, SHA-256 и отдельно нормализованную таблицу лунок. Нормализация нМ/мкМ/мМ сохраняет исходные единицы.
5. Блокировка повторных адресов лунок, неизвестных дозировочных единиц, неверных моделей, NaN/Inf, несогласованного времени и неподдержанных методов. Новый файл с уже импортированным ID планшета не перезаписывает исходный.
6. Консервативная проверка: отсутствие контроля растворителя и отрицательные исходные сигналы приводят к qc_fail; отсутствие других обязательных контролей — к qc_pending. Без SOP-порогов не создаётся статус подтверждённого результата.
7. Новый веб-раздел Клеточная активность: выбор моделей, PYZ, создание проекта, импорт CSV, вывод причин QC-предупреждений.
8. Для нового API соблюдено разделение router → service → repository → store. Старые маршруты DepMap/PRISM не переписаны.
9. Экспериментальный файл по умолчанию размещается в АКТИВНОЙ ТЕСТОВОЙ рабочей копии. Даже если MCL_ROOT указывает на старый научный архив, новый PhenotypeStore не пишет туда.

## Модель данных

- Исходный UTF-8 CSV: data/runtime/phenotype/experiments/PHENO-.../imports/SHA256.csv — неизменяемый оригинал.
- Производная таблица лунок: SHA256.rows.jsonl — с пересчитанной концентрацией в мкМ, единицей исходной записи, идентификаторами культуры и партии.
- Манифест импорта: SHA256.json — происхождение, число лунок, биологические серии, проверка качества, хеши.
- План: experiment.json — исследовательский проект. Один и тот же исходный файл не импортируется дважды.
- Реестр: config/phenotype_cell_models.tsv (не заменяет кафедральный реестр подтверждённого физического наличия).

## Научные ограничения

- Нет автоматических IC50, GR50, SI и доверительных интервалов. Система честно возвращает not_estimable / not_measured.
- Наличие необходимых контрольных типов не исключает фактическую химическую помеху МТТ. Пороговые проверки и независимый метод подтверждения ещё не реализованы.
- Пока доступен только CSV, не XLSX и не 384-луночные схемы.
- Нет верифицированных физических партий PYZ, STR-паспортов, анализов микоплазмы и данных о пассажах HEK/MRC.
- HEK293T/FT не модели рака почки; сравнение с MRC-5 не доказывает противоопухолевую селективность.
- DepMap и PRISM описывают генетические зависимости и известные вещества. Они не предоставляют экспериментальную активность наших PYZ.

## API

GET /api/phenotype/models

GET /api/phenotype/compounds

POST /api/phenotype/experiments

GET /api/phenotype/experiments/{id}

POST /api/phenotype/experiments/{id}/import

Импорт через JSON с точными байтами CSV, переданными в поле file_base64, либо текстовым csv_text для обратной совместимости.

## Шаблон исходного CSV

Расположен в apps/explorer/public/templates/phenotype_96well_template.csv.

Требуемые поля: plate_id, well_id, biological_run_id, cell_line_id, compound_id, batch_id, concentration_value, concentration_unit, exposure_h, assay_type, control_type, raw_signal.

Допустимые типы: treated, vehicle, untreated, positive_control, blank, compound_optical_blank, compound_mtt_blank, baseline_n0.

Исходная таблица должна содержать реальные измерения. Учебные данные не подставляются автоматически.

## Следующий этап

P0: реестр физических партий, STR/микоплазма/пассажи и подтверждение готовности.
P1: импорт XLSX, полная карта планшета, утверждённые SOP-пороги и проверки химических помех.
P2: концентрационные кривые, цензурирование IC50, GR50, интервалы и оценка SI только по принятым опытам.
P3: независимая интерпретация механизма после экспериментального сигнала.
P4: независимые биологические серии и подтверждение эффекта другим методом.

**Итог:** реализовано основание научно прослеживаемого хранилища первичных измерений, а не достоверное ранжирование 65 PYZ по селективной цитотоксичности.
