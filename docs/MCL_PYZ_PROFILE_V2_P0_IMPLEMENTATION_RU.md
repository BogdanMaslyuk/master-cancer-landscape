## Что изменено

1. Добавлен детерминированный построитель \`apps/api/mcl_api/pyz_profile_v2.py\` на основе существующего ответа \`OwnCompoundStore.detail()\`.
2. В существующий \`GET /api/pyz/{compound_id}\` **добавлено** поле \`profile_v2\`. Все прежние поля сохранены.
3. Ответ \`profile_v2\` валидируется строгими типами Pydantic, а клиент использует типы TypeScript.
4. Карточка \`/pyz/[id]\` переработана: структура, SMILES с копированием, обзор научной опоры, предиктивные ограничения ADMET, 13 мишеней, структурные аналоги, клеточные контексты, источники.
5. Добавлены состояния загрузки, неизвестной молекулы и ошибки со способом повторения.
6. Добавлены научные тесты и тест открытия всех 65 зарегистрированных PYZ без обязательного наличия локальных вычислительных файлов.

## Сохранённые научные границы

- Никакой вероятности связывания или IC50 для PYZ не выводится из значения Tanimoto или Ki/Kd/IC50 известного вещества.
- Резюме формируется фиксированными правилами \`P0-IDENTITY\`, \`P0-SIMILARITY-SHORTLIST\`, \`P0-NO-PYZ-BINDING\`, \`P0-NO-PYZ-CELL\`, \`P0-ADMET-MISSING\`, \`P0-NO-STRUCTURAL-SUPPORT\`, \`P0-NO-CONTEXT\`, \`P0-TEST-SHORTLIST\`, \`P0-EXPLORE-INDEPENDENTLY\`. Научные заключения привязаны к источникам.
- Данные BindingDB P0.3.6 не подключены: 4165 описаний методов не равны 4165 научно одобренным измерениям.
- Используется действующий вычислительный слой **13 основных мишеней**. Реестр 20 061 белка и 20-белковая пробная панель пока не подмешиваются.
- CRISPR/PRISM характеризуют контекст гена и известных препаратов, не экспериментальную активность PYZ.
- Ветка \`review/vnext\` и её локальные незакоммиченные научные файлы не меняются.
- Наличие линии в лабораторном реестре не гарантирует фактическую доступность; HEK293 не классифицируется как опухоль почки, MRC-5 не считается универсальным показателем безопасности.

## Источники данных

| Слой | Путь/источник | Статус |
| --- | --- | --- |
| Собственные структуры | \`config/own_compounds.tsv\` | исходный реестр 65 PYZ |
| Индивидуальный снимок ADMET | \`config/pyz_admet_snapshot.tsv\` | прогноз, не измерение |
| Сводка серии ADMET | \`config/pyz_admet_summary.json\` | **не переносить** число Ames+/DILI+ на конкретную PYZ |
| Сходство и мишени | \`data/runtime/pyz_target_evidence/pyz_target_evidence_matrix.parquet\` | локальный рассчитанный материал, не включён в Git |
| Соседи | \`data/runtime/own_compounds/target_ligand_space_similarity_top_hits.parquet\` | локальный рассчитанный материал |
| Биология моделей | \`data/runtime/pharmacology/candidate_hypotheses_v2.parquet\`, \`candidate_hypothesis_models_v2.parquet\` | отдельный контекст известных веществ |

| BindingDB P0.3.6 | внешние выводы отдельного научного аудита | **не используется** |

Если необязательных локальных файлов нет, карточка обязана показывать структуру и сообщение «нет данных», не заменяя пробелы на нули.

## Безопасный локальный запуск (только при готовности пользователя)

Работать в **отдельной папке**, не обновлять и не очищать \`mcl-vnext-review\`. Использовать отдельный git worktree или git clone из новой ветки. Локальные научные файлы не являются частью Git: для полного просмотра нужны их отдельные неизменяемые копии в \`data/runtime\` нового рабочего каталога. Никакие копии не должны замещать исходные данные.

Стандартно при настроенном Python окружении: \`uvicorn mcl_api.main:app --app-dir apps/api --host 127.0.0.1 --port 8000\`. UI: \`cd apps/explorer; npm ci; npm run dev\` с \`NEXT_PUBLIC_MCL_API_URL=http://127.0.0.1:8000\`.

При уже работающих старых процессах следует выбрать **другие порты**, а не останавливать старые без согласования. Отдельно убедиться, что оба процесса читают один и тот же новый каталог.
